# Skill list (draft for review)

Every Encounter in the game teaches or practises exactly one of these Skills. Skills unlock top to bottom within each Branch, so nothing is tested before it is taught. All four Bands (Levels 4 to 7) practise the same Skill and change only the text, vocabulary, distractors and support. Codes are from [vc2-english-levels-4-7.md](vc2-english-levels-4-7.md). "L4" or "L7" marks a Skill drawn from the edge achievement standards.

**Changes from the Q14 Branch map, for you to check:**
- VC2E5LY07 (texts reflect their time and place) moves from Pictures in words to Whose story is it?, because it is about context, not imagery.
- Formality and register (VC2E5LA01, VC2E6LA01) is added to How texts hang together. Q14 left it out, but formal and informal writing is a writing Skill, not only speaking.
- Colons and semicolons are left out. They are Level 7+, and a Skill must make sense at every Band.
