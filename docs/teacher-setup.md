# Inkwild: teacher setup (one page)

## Once, with the class

1. On each iPad, open the game's address in **Safari**.
2. Tap **Share** (the square with an arrow), then **Add to Home Screen**, then **Add**.
3. From then on, students open Inkwild **from the Home Screen icon**, not from Safari. This matters: Safari deletes saved data for websites that aren't on the Home Screen after 7 days without a visit.
4. Each student makes their captain and picks three interests. That's all the setup there is.

## Backup codes

Once a week the game asks for a fresh **Backup code**: 12 characters like `K7QM-4XWT-9HBR`. Students copy it into their book, then type it back *from the book* to prove the copy is right. If an iPad is wiped or swapped, a student taps **I have a Backup code** on the first screen and types in their latest code.

A code brings back badges, mastered Skills, difficulty and Creatures. It doesn't bring back Creatures from Swaps, shiny Creatures or free writing. Students who want those safe can use **Settings → Backup code → Also save to Files**.

## What students see, and what you don't

- There is no login, no account and no teacher dashboard. Nothing leaves the iPad.
- Difficulty adjusts silently on each Island to Levels 4, 5, 6 or 7. Students never see a level, so nobody is "on the easy stuff".
- **Settings → Show my teacher** opens a page of the student's Creatures, badges and mastered Skills, for when they want to show you.
- Settings also has three text sizes, extra letter spacing and a cream page for students who find reading tiring.
- Tapping any word reads that word aloud. Whole passages are never read out.

## What's deliberately not in the game

- **Spelling, phonics, morphology and handwriting.** These belong to OG (docs/adr/0002).
- **Speaking and listening.**
- **First Nations stories.** These are taught in class under the Koorie Cross-Curricular Protocols (docs/adr/0003).
- **Visual texts:** picture books and comics.
