# 3. No First Nations stories inside the game

Date: 2026-11-04
Status: accepted

## Context

Victorian Curriculum v2.0 English expects Aboriginal and Torres Strait Islander literature at every level (e.g. VC2E5LE01, VC2E6LE01). Research (docs/research/first-nations-texts.md) found that reproducing any First Nations story inside a public web game needs both copyright permission and cultural permission from the Traditional Owners (Wurundjeri Woi-wurrung for this school), under the Department's Koorie Cross-Curricular Protocols; the school's statutory copyright licence does not cover a public site.

## Decision

The game contains no First Nations stories, and the game's author does not write, retell or adapt any. That curriculum content stays with classroom teaching, where texts can be read with students under the protocols.

## Consequences

- No protocol or copyright breach, and no AI-imitated cultural narratives.
- The game does not cover First Nations literature; a reader seeing that gap should look here.
- If the school later gets Traditional Owner and publisher permission, an Island can be added; this is a content decision, not an architectural one.
